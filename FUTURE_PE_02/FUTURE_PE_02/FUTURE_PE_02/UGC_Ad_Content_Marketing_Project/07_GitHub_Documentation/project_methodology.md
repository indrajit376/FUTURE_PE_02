# Project Methodology

## Step 1 — Choose a real product
A real product was selected so the work resembles an agency/client assignment.

## Step 2 — Research
Only official product-page information was used for the product facts included in the scripts.

## Step 3 — Define audience
The audience was defined around short-form skincare shoppers interested in acne/oil-focused routines.

## Step 4 — Build the prompt
The master prompt uses fixed inputs:
- product
- audience
- problem
- verified features
- platform
- duration
- voice
- CTA

## Step 5 — Generate hooks
The system creates hooks across different psychological/creative angles:
- problem
- curiosity
- routine
- discovery
- objection

## Step 6 — Generate scripts
Each script follows:
**Hook → Problem → Product → Benefit/Feature → CTA**

## Step 7 — Adapt by platform
The same creative idea can be rewritten for Reels, Meta Ads or Shorts.

## Step 8 — Quality and compliance check
The prompt explicitly blocks:
- fake testimonials
- unsupported statistics
- guaranteed results
- invented offers
- invented reviews
- unverified claims

## Step 9 — Social sharing
Screenshots/snippets can be published on Instagram and LinkedIn with the supplied project caption.

## Step 10 — Reuse
To create a new campaign, replace the product inputs in the master prompt while keeping the same framework.
